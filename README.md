# Ferry

Нативный macOS-клиент для FTP / FTPS / SFTP: подключился к серверу, работаешь
с файлами прямо на нём, перетаскиваешь в обе стороны — как в Finder.

Один бинарник около 1 МБ, внешних библиотек нет: SFTP идёт через системный
`ssh`, FTP/FTPS — через системный `libcurl`.

## Что умеет

- **Профили серверов:** SFTP (пароль, файл ключа, ssh-agent), FTP, FTPS.
- **Перетаскивание из Finder в окно** — выгрузка на сервер (файлы и папки).
- **Перетаскивание из окна в Finder** — файл скачивается в момент отпускания.
- Множественное выделение (клик, ⇧-клик, ⌘-клик, ⌘A), рекурсивная работа с папками.
- Переименование, удаление, создание папок, копирование пути.
- Очередь передач с прогрессом, скоростью и отменой.
- Фильтр по имени, сортировка по колонкам, хлебные крошки пути.
- Отдельное соединение для передач — список файлов не подвисает во время закачки.

### Горячие клавиши

| | |
|---|---|
| ⌘N | новый сервер |
| ⌘R | обновить список |
| ⌘↑ | на уровень вверх |
| двойной клик | открыть папку / скачать файл |

## Требования

- macOS 14 или новее
- Xcode Command Line Tools (`xcode-select --install`)

## Сборка

```bash
./build.sh
```

Готовое приложение — `build/Ferry.app`. Установка: перетащить в «Программы»
или `cp -R build/Ferry.app /Applications/`.

Сборка подписывается ad-hoc, поэтому при первом запуске macOS может попросить
подтвердить открытие: ПКМ по приложению → «Открыть».

## Безопасность

- Пароли хранятся только в Связке ключей macOS, в файле профилей их нет.
- SFTP работает поверх штатного `ssh`, поэтому автоматически подхватываются
  ваши ключи из `~/.ssh`, `ssh-agent` и настройки из `~/.ssh/config`.
- Ключ нового сервера принимается автоматически, **изменившийся — отклоняется**
  с подсказкой (защита от подмены сервера).

## Как устроено

| Задача | Решение |
|---|---|
| Интерфейс | SwiftUI + AppKit |
| SFTP | системный `ssh` + подсистема `sftp`, свой слой протокола v3 |
| FTP / FTPS | системный `libcurl` (AUTH TLS, пассивный режим) |
| Пароли | Связка ключей macOS |
| Профили серверов | `~/Library/Application Support/Ferry/servers.json` |

## Тесты

Сквозные тесты гоняются против настоящих SFTP- и FTP-серверов в docker
(нужен запущенный Docker):

```bash
Tools/test_servers.sh up
swift test
Tools/test_servers.sh down
```

Проверяются: подключение, листинг, выгрузка и скачивание с побайтовой сверкой,
переименование, рекурсивное удаление, отмена передачи, отказ при неверном пароле
и выгрузка файла по запросу Finder при перетаскивании. Тестовые серверы
поднимаются на `localhost` с одноразовыми учётными данными из `Tools/test_servers.sh`.
